# ShakhedDrones

Плагин боевых дронов для **Paper 1.21.11**, Java 21. Автор: **nome**.

## Сборка

```powershell
.\gradlew.bat build
```

Готовый файл появится в `build/libs/`. Перенесите его в папку `plugins` Paper-сервера и перезапустите сервер.

## Команды

- `/drone list` — список идентификаторов.
- `/drone give <shakhed|fp-1|geran-4|jet|copter> [количество]` — выдать дрон.
- `/drone give pad` — выдать стартовую площадку.
- `/drone give battery` — выдать батарею коптера.
- `/drone give controller` — выдать пульт коптера.
- `/drone give ew` — выдать станцию РЭБ.
- `/drone give radar` — выдать локатор воздушных целей.
- `/drone give ew-battery` — выдать конечную батарею питания РЭБ.
- `/drone give wire` — выдать визуальный провод РЭБ, который прокладывается как красная пыль.
- `/drone give aa` — выдать управляемую зенитку.
- `/drone give missile-station` — выдать ракетную станцию, занимающую площадку 3×3.
- `/drone give fuel-canister` — выдать канистру на 20 единиц топлива.
- `/drone give flamingo|oreshnik|iskander|loitering` — выдать выбранную ударную ракету.
- `/drone give auto-pro` — выдать автоматическую систему ПРО.
- `/drone target <x> <y> <z> <высота>` — задать цель и эшелон дальнего дрона (до Y=140).
- `/drone exit` — принудительно выйти из управления коптером и вернуться к точке запуска.
- `/drone reload` — перечитать `config.yml`.

Команды доступны операторам (`shakheddrones.admin`). Использовать дроны могут все игроки (`shakheddrones.use`).

## Использование

1. Поставьте стартовую площадку на землю и кликните по её верхней стороне предметом крупного дрона. Коптер можно поставить на обычный блок.
2. Кликните TNT по установленному аппарату, чтобы загрузить заряд. Лимиты задаются в конфиге.
3. Для коптера отдельно вставьте батарею.
4. Для крупного аппарата задайте цель и высоту командой `/drone target`, затем запустите его. Высота набирается по наклонной траектории, а подъём уменьшает остаток топлива.
5. Для запуска коптера возьмите пульт в основную руку. `W/S` — вперёд/назад, `A/D` — в стороны, `Space/Shift` — вверх/вниз; без ввода коптер зависает. `F` сбрасывает один TNT. Игрок неуязвим во время управления и после завершения возвращается к точке запуска.

## РЭБ и ПВО

- Станция РЭБ работает только от специальной батареи. Соедините станцию и батарею проводом: ПКМ по станции, затем ПКМ по батарее. Заряд расходуется каждую секунду даже в простое. Подавленный дрон сбивается с курса и после длительного подавления падает.
- Локатор подключается таким же проводом к батарее, обнаруживает дроны в своём радиусе и рассылает предупреждение с координатами и типом цели.
- Зенитка управляется игроком: установите её, нажмите по ней ПКМ, наводитесь взглядом и стреляйте ЛКМ. `F` переключает пули/ракеты, `Shift` покидает место оператора. Боезапас берётся из установленных рядом ящиков: 500 пуль или 6 ракет.
- Сейчас оборонительные системы нейтральны и воздействуют на все дроны. Параметры дальности, урона и перезарядки находятся в `config.yml`.

## Ракетная станция и ПРО

1. Установите ракетную станцию на свободном участке 3×3 — все девять блоков станут её основанием.
2. Поставьте рядом топливные канистры и батарею РЭБ. Проводом нажмите ПКМ по любой части станции, затем по батарее.
3. Задайте точку и эшелон командой `/drone target <x> <y> <z> <высота>`.
4. Возьмите «Фламинго», «Орешник», «Искандер» или баражирующую ракету и нажмите ПКМ по станции. Ракета и требуемое количество топлива будут израсходованы.
5. Для автоматической ПРО поставьте саму установку, контейнер ракет, канистру и батарею в радиусе снабжения. Подключите батарею проводом. ПРО самостоятельно ищет ракеты, расходует по одной противоракете и единице топлива; базовая вероятность попадания — 65%.

Радар обнаруживает не только дроны, но и ударные ракеты. Баражирующая ракета выполняет круг над районом цели перед пикированием. Параметры каждого типа и ПРО находятся в разделе `missiles` файла `config.yml`.

При исчерпании запаса хода крупный дрон пикирует, а коптер падает. FP-1 наносит дополнительный урон живым целям, Герань-4 поджигает район попадания, реактивный дрон создаёт вторую ударную волну. Неиспользованный TNT усиливает взрыв при столкновении.

Все дальности, скорости, мощности и лимиты находятся в `plugins/ShakhedDrones/config.yml`.
